# CODSOFT
Codsoft Data Science Internship Projects

This repository contains the projects completed as part of the CodeSoft Student Internship Program (CIP).
Projects Included

1. Titanic Survival Prediction
Built a classification model to predict whether a passenger survived or not using machine learning techniques.

2. Iris Flower Classification
Developed a model to classify iris flowers into different species based on their measurements.

3. Movie Rating Prediction
Created a regression model to predict movie ratings based on features like genre and director.

4. Credit Card Fraud Detection
Built a classification model to detect fraudulent transactions using imbalanced data handling techniques.

Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

Concepts Covered
- Data Preprocessing
- Feature Engineering
- Classification & Regression Models
- Model Evaluation (Accuracy, Precision, Recall, F1-score)
